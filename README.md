# SpecsReleases

Built artifacts of the specs app (APK and language packs), published by `make release`. The app reads `latest.json` from the `index` release. No source here.

The language packs include dictionary data (JMdict, KANJIDIC2, Wiktionary, CC-CEDICT: CC BY-SA 4.0) and OCR weights (charspot, nar: CC BY-NC-SA 4.0), for personal, non-commercial use. Credits are in the app (About).
